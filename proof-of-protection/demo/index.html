    What the evidence badges mean
    Hardware key
    Signed by a key locked in the device's security chip (TPM or Secure Enclave). The strongest. Not used in this prototype.
    Platform-verified
    Read from Microsoft 365's own records by a read-only connector.
    Scan-verified
    Checked from outside, against the firm's own domain, by the vendor's scanner.
    Staff-attested
    A person's signed, time-stamped record (for example a call-back). Honest about being a person's word.
    Software key
    Signed by a key stored in software on the device. This prototype uses software keys everywhere; production Windows devices use TPM-bound keys.

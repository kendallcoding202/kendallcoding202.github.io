Clutterkin privacy policy

Clutterkin is an iPhone game by Kendall Sorenson. Last updated 19 November 2026.

The short version

Clutterkin collects nothing. It has no accounts, no advertising, no analytics and no tracking, and the game never connects to the internet.

What the game stores, and where

Your progress (your friends, the places you have calmed, your settings and the name you chose for your house-sitter) is saved on your device, in the app's own storage. It is not sent to us or to anyone else. Your device's own backup, if you use one, includes it as it includes every app's data.

What the game does not do

  • It does not ask for your name, email, location, contacts, photos, camera or microphone.
  • It does not track you across apps or websites.
  • It contains no third-party code that does either.

Purchases

There is nothing to buy inside the game.

Children

The game is suitable for children, and it collects nothing from anyone, of any age.

These web pages

This page is hosted by GitHub Pages, which, like any web host, receives the address of a visitor's device when a page is requested. The game itself never visits these pages.

Deleting your data

Delete the app and the save goes with it. Inside the game, Settings has Start over, which erases the save and keeps the app.

Changes

If any of this ever changes, this page will say so, with the date.
